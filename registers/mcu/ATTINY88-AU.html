EECREEPROM Control Registerp. 25

offset 0x3F · 8 bits · reset 0b00xx00x0 · access R/W

BitsFieldAccessResetWhat it does
5:4EEPMR/WxEEPROM programming mode: picks what a write to EEPE does, either an atomic erase-then-write or an erase or a write alone. Writes to EEPM are ignored while EEPE is set. Reset returns it to 0b00 unless the EEPROM is busy programming.
EEPM1EEPM0Programming TimeOperation
003.4 msErase then write, as one atomic operation
011.8 msErase, only
101.8 msWrite, only
11-Reserved
3EERIER/W0EEPROM ready interrupt enable: 1 enables the interrupt, which fires while non-volatile memory can accept programming, as long as the SREG I-bit is 1; 0 disables it.
2EEMPER/W0EEPROM master write enable: while it is 1, writing EEPE to 1 within four clock cycles programs the EEPROM at the selected address; with it 0, EEPE has no effect. Hardware clears it four clock cycles after it is set.
1EEPER/WxEEPROM write strobe: writing 1, with address and data set up and EEMPE written to 1 in the four cycles before, writes EEDR into the EEPROM; without EEMPE nothing is written. Write sequence: wait for EEPE to read 0, wait for SPMCSR.SELFPRGEN to read 0 (not needed if software never writes Flash), set EEAR and EEDR if needed, write EEMPE to 1 with EEPE 0, then write EEPE to 1 within four cycles. An interrupt between those last two steps makes the write fail, and an interrupt routine that touches EEAR or EEDR during another access spoils that access. No EEPROM write can happen while the CPU is writing Flash. Hardware clears EEPE when the write time has passed; the CPU halts for two cycles after EEPE is set.
0EERER/W0EEPROM read strobe: with the address in EEAR, writing 1 reads the byte, which is ready at once; the CPU halts four cycles. A read, or a change of EEAR, cannot happen while a write is in progress, so check EEPE first.

BitsFieldAccessResetWhat it does

4CTPBR/W0Clear temporary page buffer: writing it while the buffer is being filled empties the buffer, losing its data.

1PGERSR/W0Page erase: written to 1 together with SELFPRGEN, makes the next SPM within four clock cycles erase the page addressed by the high part of the Z-pointer; R1 and R0 are ignored. Clears itself when the erase completes or if no SPM follows within four cycles. The CPU halts during the operation.
0SELFPRGENR/W0Self programming enable: enables SPM for the next four clock cycles. Written with CTPB, RFLB, PGWRT or PGERS, the next SPM does that operation; written alone, the next SPM stores R1:R0 in the temporary page buffer at the Z-pointer address, ignoring the Z LSB. Clears itself when the SPM completes or if none comes within four cycles; stays 1 until a page erase or page write finishes. Any value of the low five bits other than 10001, 01001, 00101, 00011 or 00001 has no effect.
