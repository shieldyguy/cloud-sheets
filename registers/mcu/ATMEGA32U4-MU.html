BitsFieldAccessResetWhat it does
5:4EEPMR/WxPicks what a write of EEPE does: erase and write together as one atomic operation, erase only, or write only. Writes to it are ignored while EEPE is 1. Reset returns it to 0b00 unless the EEPROM is in the middle of programming.

3EERIER/W01 enables the EEPROM Ready interrupt when the I bit in SREG is set; 0 disables it. The interrupt keeps firing for as long as EEPE is 0.
2EEMPER/W0Arms an EEPROM write: while it is 1, setting EEPE within four clock cycles writes the data to the selected address; while it is 0, setting EEPE does nothing. Hardware clears it four clock cycles after software sets it.
1EEPER/WxWrite strobe for the EEPROM: with address and data set up, writing it to 1 starts the write, but only if EEMPE was set to 1 first. Write sequence: wait for EEPE to read 0; wait for SELFPRGEN in SPMCSR to read 0 (needed only when a boot loader can program the Flash); optionally load EEAR and EEDR (in either order); write EEMPE to 1 with EEPE 0; within four clock cycles write EEPE to 1. An interrupt between the last two steps makes the write fail, since EEMPE times out, and an interrupt routine that touches EEAR or EEDR during another EEPROM access spoils that access. No EEPROM write can happen while the CPU is writing the Flash. Hardware clears EEPE when the write time has passed; the CPU stops for two cycles after EEPE is set. Keeping the I bit in SREG clear through every step avoids both failures. Software may poll EEPE for 0 before writing the next byte.
0EERER/W0Read strobe: with the address in EEAR, writing 1 starts an EEPROM read. The read takes one instruction and the data is ready at once; the CPU stalls four cycles before the next instruction. Poll EEPE first: while a write is under way neither a read nor a change of EEAR is possible. EEPROM accesses are timed by the calibrated oscillator.

OSCCALOscillator Calibration Registerp. 32

offset 0x66 · 8 bits · reset 0bxxxxxxxx · access R/W

  • Initial value of bits 7:0 printed as Device Specific Calibration Value.
  • The diagram prints no address; the register summary gives 0x66.
BitsFieldAccessResetWhat it does
7:0CALR/WxTrims the calibrated internal RC oscillator. Reset loads the factory value, which gives 8.0MHz at 25°C; software may write another. The range is ±40%, linear, about 0.4% a step; 0x00 is the lowest frequency and 0xFF the highest, and with typical process at 25°C 8MHz is code 127. Drift with temperature is close to linear but its slope depends on the process; measuring the frequency at two temperatures, which the on-chip temperature sensor makes possible, gives the slope, and the oscillator can then be trimmed against measured temperature. The same oscillator times EEPROM and Flash writes, so those times move with it; above 8.8MHz an EEPROM or Flash write may fail.
