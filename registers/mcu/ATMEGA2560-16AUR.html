EECRThe EEPROM Control Registerp. 34

offset 0x3F · 8 bits · reset 0b00xx00x0 · access R/W

BitsFieldAccessResetWhat it does
5:4EEPMR/WxEEPROM programming mode: picks what a write of EEPE does, an atomic erase-and-write or an erase or a write alone. Writes to EEPM are ignored while EEPE is set; reset clears EEPM to 0b00 unless the EEPROM is busy programming.
EEPM1EEPM0Programming TimeOperation
003.4msErase and write in one atomic operation.
011.8msErase only
101.8msWrite only
11-Reserved for future use
3EERIER/W0EEPROM Ready interrupt enable: with the SREG I bit set, 1 enables the interrupt and 0 disables it; the interrupt requests continuously while EEPE is clear.
2EEMPER/W0EEPROM master programming enable: with it at 1, an EEPE write of 1 inside the next four clock cycles programs the selected EEPROM address; with EEMPE at 0, setting EEPE does nothing. Hardware clears EEMPE four clock cycles after software sets it.
1EEPER/WxEEPROM programming enable, the write strobe: with address and data set up, write EEPE to 1 within four clock cycles after setting EEMPE (written with EEPE at 0) to start the write. Before starting, wait for EEPE and SPMCSR.SPMEN to read 0; EEAR and EEDR may be written in either order. No EEPROM write can run while the CPU is writing Flash. An interrupt between setting EEMPE and setting EEPE makes the write fail, and an interrupt routine that touches EEAR or EEDR during another EEPROM access makes that access fail. Hardware clears EEPE when the write is done; setting EEPE halts the CPU for two cycles.
0EERER/W0EEPROM read enable, the read strobe: with the address in EEAR, write 1 to read; the data is ready at once and the CPU halts for four cycles. While a write is in progress the EEPROM cannot be read and EEAR cannot be changed.

BitsFieldAccessResetWhat it does
7:0CALR/WxOscillator calibration for the calibrated internal RC oscillator: loaded with the factory value at reset and writable to change the frequency. CAL7 picks the low (0) or high (1) range, the two ranges overlapping so 0x7F runs faster than 0x80; CAL6:0 tune within the range, 0x00 slowest and 0x7F fastest. The oscillator times EEPROM and Flash writes, which may fail if it is calibrated above 8.8MHz while writing.

offset 0x55 · 8 bits · reset 0x00 · access R/W

BitsFieldAccessResetWhat it does
7JTDR/W0JTAG interface disable: 0 leaves the JTAG interface enabled when the JTAGEN fuse is programmed, 1 disables it. To change it, write the new value twice within four cycles. It must not be changed while the on-chip debug system is in use.
4PUDR/W0Pull-up disable: 1 turns off all I/O port pull-ups, even on pins whose DDxn and PORTxn (0b01) would enable them.
1IVSELR/W0Interrupt vector select: 0 puts the interrupt vectors at the start of Flash, 1 moves them to the start of the boot loader section, whose address the BOOTSZ fuses set. To change it, write IVCE to 1, then within four cycles write IVSEL while writing IVCE to 0. Interrupts are off from the cycle IVCE is set until after the instruction following the IVSEL write, or for four cycles if IVSEL is not written; SREG I is not touched. With vectors in the boot section and BLB02 programmed, interrupts are off while running from the application section; with vectors in the application section and BLB12 programmed, they are off while running from the boot section.
0IVCER/W0Interrupt vector change enable: must be written to 1 before IVSEL can be changed; hardware clears it four cycles later or when IVSEL is written. Setting it disables interrupts.
