3EERIER/W0EEPROM ready interrupt enable: 1 enables the EEPROM Ready interrupt when SREG.I is 1, 0 disables it. The interrupt keeps firing for as long as EEPE is 0.
2EEMPER/W0EEPROM master programming enable: while EEMPE is 1, setting EEPE within four clock cycles writes the EEPROM at the selected address; while it is 0, setting EEPE does nothing. Hardware clears EEMPE four clock cycles after software sets it.
1EEPER/WxEEPROM programming enable, the write strobe: with address and data set up and EEMPE written to 1 first, writing EEPE to 1 starts the write; without EEMPE no write happens. Write sequence: wait for EEPE to read 0; wait for SPMCSR.SPMEN to read 0; load EEAR and EEDR if needed (either order); write EEMPE to 1 while writing EEPE to 0; within four clock cycles write EEPE to 1. The EEPROM cannot be written while the CPU writes Flash; the SPMEN wait matters only when a boot loader writes Flash. An interrupt between the last two steps makes the write fail as EEMPE times out, and an interrupt routine that touches EEAR or EEDR during an access makes that access fail; keeping SREG.I cleared through the steps avoids both. Hardware clears EEPE when the write time has passed. Setting EEPE halts the CPU for two cycles before the next instruction.
0EERER/W0EEPROM read enable, the read strobe: with the address in EEAR, writing EERE to 1 starts the read, which completes in one instruction with the data ready at once; the CPU halts four cycles before the next instruction. EEPE is polled before a read: while a write is in progress the EEPROM cannot be read nor EEAR changed. Access timing comes from the calibrated oscillator.

OSCCALOscillator Calibration Registerp. 40

offset 0x66 · 8 bits · reset 0bxxxxxxxx · access R/W

  • Initial value of bits 7:0 printed as Device Specific Calibration Value.
BitsFieldAccessResetWhat it does
7:0CALR/WxOscillator calibration: trims the calibrated internal RC oscillator for process variation. Reset loads a factory value giving the factory calibrated frequency; software may write other values to change the frequency, and calibration outside the specified range is not guaranteed. The oscillator also times EEPROM and Flash writes, so their times move with it; calibrating above 8.8 MHz while writing EEPROM or Flash can make the write fail. CAL7 selects the range, 0 the lower and 1 the higher; the two ranges overlap, so 0x7F is faster than 0x80. CAL6:0 tune within the range, 0x00 slowest and 0x7F fastest.
