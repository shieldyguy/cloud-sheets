3EERIER/W0EEPROM ready interrupt enable: 1 enables the interrupt when SREG.I is 1, 0 disables it. The interrupt requests continuously while EEPE is 0, and not during an EEPROM write or SPM.
2EEMPER/W0EEPROM master write enable: while 1, setting EEPE within 4 clock cycles writes the EEPROM at the selected address; while 0, setting EEPE does nothing. Hardware clears it 4 clock cycles after software sets it.
1EEPER/WxEEPROM write enable: the write strobe. With address and data set up, write EEMPE to 1 (with EEPE 0), then EEPE to 1 within 4 clock cycles; without EEMPE no write happens. Sequence: wait for EEPE 0, wait for SPMCSR.SPMEN 0 (only when a boot loader writes Flash), set EEAR and EEDR (in either order, both optional), set EEMPE, then EEPE. No EEPROM write is possible while the CPU writes Flash. An interrupt between setting EEMPE and EEPE makes the write fail, and an interrupt routine that touches EEAR or EEDR spoils an access it interrupts. Hardware clears EEPE when the write time has passed; setting it halts the CPU for 2 cycles.
0EERER/W0EEPROM read enable: the read strobe. With EEAR set, write 1 to read; the read takes one instruction, the data is ready at once, and the CPU halts for 4 cycles before the next instruction. Poll EEPE first: while a write runs, neither a read nor a change of EEAR is possible. EEPROM accesses are timed by the calibrated oscillator.

BitsFieldAccessResetWhat it does
7:0CALR/WxOscillator calibration: trims the calibrated internal RC oscillator. Reset loads the factory value; software may write another to change the frequency, and calibration outside the specified range is not ensured. This oscillator times EEPROM and Flash writes, so their times change with it; above 8.8MHz those writes may fail. CAL7 picks the low (0) or high (1) range, and the ranges overlap (0x7F is faster than 0x80); CAL6:0 tunes within the range, 0x00 slowest and 0x7F fastest.
